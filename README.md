# Orbal — Site officiel

## Déploiement sur Vercel

1. Crée un repo GitHub et pousse ce dossier
2. Va sur vercel.com → New Project → importe le repo
3. Framework : Next.js (détecté automatiquement)
4. Deploy → ton site est en ligne

## Développement local

```bash
npm install
npm run dev
```

## Avant de mettre en ligne
- Remplacer [NOM PRÉNOM] dans pages/index.js (mentions légales)
